# Pet art credits

Six creatures, all **expressive and animated**: each renders from per-state sprite **strips** at
`pets/<key>/<state>.png`, generated by `scripts/gen-pet-sprites.mjs` from the source art below.
States are the mood ladder + the eating action: `happy`, `sleeping`, `sad`, `angry`, `eating`.
**Bump `SPRITE_VERSION` in `src/components/pet/pet-art.ts` whenever these PNGs change** (filenames
stay constant, so clients must be told to refetch); `pet-frames.ts` (also generated) records each
strip's frame count + per-frame duration so `<Pet>` can play it.

## Cat, Dog, Axolotl, Pig, Frog, Capybara — self-made "Chibi Animal Megapack"
Generated by the project owner (exported from the `baddest` asset project). Owned by the project — no
third-party license restrictions. Source frames vendored at `art-src/chibi/<animal>/<state>/` (256×256,
6 frames per state, margin-normalized); see `art-src/chibi/SOURCE.md`. Each state is a real multi-frame
animation, stitched into a strip and played frame-by-frame. The cat eats from a bowl, the pig munches an
apple, etc.

## Mood & animation
A creature's mood comes from its happiness value (see `src/lib/rewards/wellbeing.ts`): studied today →
**happy**; ~1 day idle → **sleeping**; ~2 days → **sad**; ~3+ days → **angry**. Feeding a treat plays
the transient **eating** state for a couple seconds. `<Pet>` swaps the strip per state and animates it.

## Accessories — generated vector shapes
`items/{cap,glasses,scarf,bow}.png` are simple shapes drawn in `gen-pet-sprites.mjs`; placement is
tuned per-creature via the `anchors` in `src/lib/rewards/catalog.ts`.
